# Ayuda del panel de administración

`help.html` es el manual del **visor público**. Esta carpeta guarda el
contenido de ayuda del **panel de administración**, listo para publicarse en
una página propia (`admin-help.html`) o en la sección de ayuda del panel.

## Contenido

- [Demanda no satisfecha](demanda-no-satisfecha.md)

## Reglas

- Cada tema vive en un archivo Markdown; no duplicar el contenido en
  `help.html`.
- Escribir en español neutro para Chile, sin jerga innecesaria.
- No incluir datos personales, secretos ni ejemplos con información real.
- Cuando el panel tenga su propia página de ayuda, estos archivos son la
  fuente canónica del contenido.
